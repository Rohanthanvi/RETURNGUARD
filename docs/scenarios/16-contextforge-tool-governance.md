# ContextForge Tool Governance

## What this shows

This scenario demonstrates that each agent receives only the MCP tools required for its role.

## Watch it live

1. Start an agent pipeline run.
2. Open the trace.
3. Observe tool calls from the agents.
4. Verify that calls are routed through ContextForge.
5. Compare available tools between agents.

## Why it matters

Least-privilege tool access limits what an individual agent can do.
