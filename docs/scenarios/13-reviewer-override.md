# Reviewer Override

## What this shows

This scenario demonstrates how a human reviewer can override an agent recommendation while preserving the audit trail.

## Watch it live

1. Open the reviewer dashboard.
2. Open an escalated return.
3. Review the agent decision.
4. Choose the human decision.
5. Confirm the decision.
6. Observe the updated status and audit information.

## Why it matters

The workflow keeps humans in control of consequential return decisions while recording the human decision for auditing.
