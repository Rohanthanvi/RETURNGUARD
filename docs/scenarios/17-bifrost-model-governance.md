# Bifrost Model Governance

## What this shows

This scenario demonstrates per-agent model permissions, rate limits, and budget controls through Bifrost.

## Watch it live

1. Start a pipeline run.
2. Open the trace.
3. Identify the model used by each agent.
4. Compare the model scopes for different agents.
5. Review the Bifrost virtual-key configuration.

## Why it matters

Model access is controlled independently for each agent.
