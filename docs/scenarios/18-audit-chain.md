# Audit Chain Verification

## What this shows

This scenario demonstrates verification of the tamper-evident audit log.

## Watch it live

1. Run a return through the pipeline.
2. Perform a reviewer action.
3. Observe the audit entries.
4. Run the audit-chain verification command.
5. Confirm that the hash chain remains valid.

## Why it matters

Important system and human actions are recorded in a hash-chained audit log.
