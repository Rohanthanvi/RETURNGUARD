# Request More Information

## What this shows

This scenario demonstrates the reviewer request-information workflow.

## Watch it live

1. Open an escalated return.
2. Select request information.
3. Enter a question for the customer.
4. Submit the request.
5. Open the customer view.
6. Answer the question.
7. Observe the case re-enter the pipeline.

## Why it matters

Ambiguous cases can gather additional information instead of forcing an immediate decision.
